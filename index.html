Quick Reference & Module Functions Guide

🔒 100% Client-Side Privacy

Your audio files are never uploaded to any cloud server. All audio decoding, Web Worker FFT signal processing, and rendering happen locally inside your browser. Unreleased tracks stay 100% secure on your computer.

1. Control Bar & Routing

Load audio via file selection or full-page drag & drop. Toggle playback with Spacebar. Select Left Only or Right Only to isolate channels, or turn Mono: ON to audition mono-compatibility.

2. Stereo Waveform Overview

Visualizes track amplitude over time. Bar colors reveal phase health: Green = In-Phase, Yellow = Wide Stereo, and Red = Out-of-Phase / Anti-Phase (risk of mono cancellation).

3. Goniometer / Phase Scope

Shows 2D stereo soundfield distribution and phase correlation meter. Switch between Scope: Raw Track View (unfiltered stereo audio file) and Scope: Post Mono ON Routing View (monitored signal that collapses visually into a straight vertical line in mono mode).

4. Spectrum Analyzer (RTA)

Real-time frequency response curves for Left (Cyan) and Right (Magenta) channels. Automatically tracks isolated single channels when Left/Right Only is selected. Features logarithmic Hz bounds & frequency presets.

5. Interactive Spectrogram

High-resolution 4096-FFT dual-channel spectral visualizer. Features Mel & Linear frequency scaling, 64x horizontal zoom, variable gain boost, and crosshair frequency/timestamp reading.
